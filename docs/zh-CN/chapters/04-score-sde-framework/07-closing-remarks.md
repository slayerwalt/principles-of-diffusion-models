# 4.7 结语 {#sec-ch4-cr}

本章是整个论述中的关键一步，将变分视角与基于 score 视角中的离散时间扩散过程，统一到一个简洁的连续时间框架中。我们说明，DDPM 与 NCSN 都可理解为具有不同漂移／波动系数的随机微分方程（SDE）的离散化。

这一框架的基石是相应逆时间 SDE 的存在，它正式定义了一个逆转噪声扰动的生成过程。关键在于，逆向过程的漂移只依赖一个未知量：每个时刻边缘数据分布的 score 函数 $\nabla_{\mathbf{x}}\log{p_{t}(\mathbf{x})}$。这一认识确立了 score 函数在生成建模中的核心地位。

此外，我们引入了一个完全确定性的对应过程——概率流常微分方程（PF-ODE），其解轨迹沿着与 SDE 相同的边缘密度 $\{p_{t}\}$ 演化。这种一致性由底层的 Fokker–Planck 方程保证。它意味着，复杂的生成任务本质上等价于求解微分方程。训练归结为学习定义方程向量场的 score 函数，采样则成为数值积分问题。

PF-ODE 这一纯确定性流，为通向扩散模型的第三个也是最后一个视角提供了有力桥梁。学习由速度场支配的确定性变换，是近年一大类重要生成模型的核心原则。下一章中，我们将：

1.  探索这一基于流的视角，从其在归一化流与神经 ODE 中的起源开始。

2.  说明这一视角如何导向现代的流匹配框架，后者直接学习速度场，在分布之间输运样本。

最终，我们将看到，从随机原理推导出的确定性 PF-ODE，也能够从完全不同的基于流的起点构造并推广，从而完成对扩散建模的统一理解。
