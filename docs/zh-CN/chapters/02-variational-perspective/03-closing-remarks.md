# 2.3 结语 {#sec-ch2-cr}

本章从变分视角追溯了扩散模型的起源。我们首先介绍变分自编码器（VAE），这是一类基础生成模型，通过证据下界（ELBO）学习数据与结构化潜空间之间的概率映射。随后，我们看到层次 VAE（HVAE）如何通过堆叠潜变量层来扩展这一思想，引入逐步、由粗到细地生成数据这一有力的概念。不过，这些模型在训练稳定性和样本质量方面仍然面临挑战。

接着，我们将 Denoising Diffusion Probabilistic Models（DDPM）视为这一变分框架中的一次关键发展。通过将编码器固定为逐渐加噪的过程，并且只学习逆向去噪步骤，DDPM 巧妙地避开了 HVAE 的训练不稳定性。我们还说明，DDPM 同样通过最大化对数似然的变分界来训练，其训练目标可以分解为一系列简单的去噪任务。这种计算可行性源自一种有效的条件化策略：将难以计算的边缘目标转化为可计算的条件目标。这一思路会在扩散模型中反复出现。

这一变分框架为 DDPM 提供了完整而有力的基础，同时，基于能量的建模原理还给出了另一种同样基础的理解视角。下一章将介绍这一基于 score 的视角：

1.  我们将从学习去噪转移概率 $p_{\boldsymbol{\phi}}(\mathbf{x}_{i-1}\vert\mathbf{x}_{i})$，转向直接学习数据对数密度的梯度，即 score 函数。

2.  我们将看到，这一源自 EBM 的方法如何发展出 Noise Conditional Score Networks（NCSN），并揭示 DDPM 学得的噪声预测（$\boldsymbol{\epsilon}$-预测）与 score 函数本身之间深刻的数学等价关系。

这一视角将带来新的认识，也将成为后续建立扩散模型统一连续时间框架的另一块基石。
