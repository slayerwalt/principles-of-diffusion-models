# 2. 变分视角：从 VAE 到 DDPM {#ch-variational}

本章从变分视角理解扩散模型。我们首先介绍变分自编码器（VAE）。它用潜变量表示数据，并通过最大化对数似然的一个可计算下界进行训练。在这一设定中，学得的编码器将观测数据映射到潜变量，学得的解码器再将潜变量映射回观测数据，从而形成完整的建模过程。

在这一模式的基础上，层次变体（层次 VAE）通过堆叠多个潜变量层，捕捉不同尺度上的结构。Denoising Diffusion Probabilistic Models（DDPM）在概念上遵循类似的框架：编码器被固定为一个逐渐将数据映射到噪声的前向加噪过程，训练则学习一个解码器，通过一系列去噪步骤逆转这一路径，无需联合训练编码器和解码器。从这一视角看，VAE、层次 VAE 和扩散模型都在优化由变分界定义的似然替代目标，这为本章介绍的方法提供了共同基础。

**读完本章后，你将能够……**

-   理解为什么在难以进行精确最大似然训练时，VAE 会优化 ELBO；

-   看出 DDPM 如何通过固定的加噪过程和学得的逆向过程，将 VAE 的潜变量视角扩展到多个带噪层；

-   理解如何利用条件化技巧，将困难的逆向去噪问题转化为可计算的训练目标；

-   比较均值预测、干净数据预测和噪声预测，并理解它们如何表示同一底层去噪信息；

-   通过 ELBO，将实际使用的 DDPM 去噪损失与其变分基础联系起来。
