# 12. 统一原则与未来方向 {#ch-epilogue}

> *抽象的目的不是含糊其辞，而是创造一个能够做到绝对精确的新语义层次。*
>
> — Edsger W. Dijkstra

本书的每一章都围绕同一个主题：概率质量如何在给定变换下移动，以及如何逆转、近似或利用这一运动生成数据。在最后这一章中，我们将整体回顾，明确展示这种结构上的统一。首先重访贯穿前文的变量变换原则（[第 12.1 节](01-density-transport-backbone.md#sec-epilogue-backbone)），随后说明相同的概率输运视角如何通过 Markov 核与连续时间 Markov 链扩展到离散状态空间（[第 12.2 节](02-discrete-spaces.md#sec-epilogue-discrete)），最后讨论更广阔的研究图景（[第 12.3 节](03-closing-remarks.md#sec-epilogue-closing)）。

**学完本章后，你将能够……**

-   解释概率输运如何成为贯穿本书各生成建模框架的共同原则；

-   将连续空间中由连续性方程和 Fokker–Planck 方程描述的概率演化，与有限状态下的对应形式——主方程——联系起来；

-   解释离散状态空间中的逆向建模如何变化，其中转移核、概率比与跳跃率取代普通 Euclidean 空间中的 score 和速度场；

-   比较连续与离散状态空间中的变分、score／比值及流视角，辨认其共通之处与变化之处。

**阅读路线。** 本章作为尾声，重在综合，而不引入新的方法。阅读时应关注：从连续状态空间转向离散状态空间时，哪些原则保持不变，哪些数学对象必须改变。
