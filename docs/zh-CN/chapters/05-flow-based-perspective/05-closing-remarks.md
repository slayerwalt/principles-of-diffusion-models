# 5.5 结语 {#sec-ch5-cr}

本章阐明了扩散模型的第三个、也是最后一个基础视角，其根源是确定性流的原理。我们从归一化流（NF）出发，它利用变量替换公式，在简单先验与数据分布之间学习精确、可逆的映射。随后看到这一概念如何通过神经 ODE 演变为连续时间过程，由学得的速度场支配变换。不过，这一方法的显著缺点，是训练循环内部需要昂贵的 ODE 模拟。

现代流匹配（FM）框架为这一挑战提供了简洁、高效的解决方案。通过预定义概率路径 $\{p_{t}\}_t$ 及满足连续性方程的相应速度场，FM 为 ODE 流建立明确目标。与变分视角及基于 score 的视角一样，FM 使用了有力的条件化技巧，将匹配边缘速度场这一不可计算问题，转化为对已知条件速度进行简单、可计算的回归，使训练完全无须模拟。这一视角将扩散模型本身重新理解为一个特殊情形：学习确定性流，将 Gaussian 先验输运到数据分布。

随着基于流视角的引入，我们对扩散建模三个概念支柱的介绍已经完整。在这一过程中出现了一个显著的共同模式：尽管每个框架分别源于 VAE、EBM 或 NF，它们最终都走向连续时间生成过程，并依赖条件化策略实现可计算的学习。

下一章将把这些并行线索汇总为一个统一框架。我们将：

1.  正式说明变分、基于 score 与基于流的视角，在基础层面上具有数学等价性，而不只是彼此类似。

2.  展示 Fokker–Planck 方程如何成为支配三种视角下密度演化的普遍规律，揭示它们都是描述同一核心生成原理的不同视角。

这一统一视角将帮助我们完整、系统地理解现代扩散范式。
