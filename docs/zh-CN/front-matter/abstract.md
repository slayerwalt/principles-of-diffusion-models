# 摘要 {#abstract}

本书聚焦于推动扩散模型发展的原理，追溯这些原理的起源，并说明不同的表述如何源自共同的数学思想。

扩散建模首先指定一个*前向扰动过程*，逐渐将数据转化为噪声。这一前向过程通过定义一个连续的中间分布族，将数据分布与简单的噪声分布连接起来。扩散模型的核心目标是构造另一个沿相反方向运行的过程，在将噪声转化为数据的同时，恢复前向扰动过程所定义的那些中间分布。

我们介绍了将这一思想形式化的三种互补方式。*变分视角*受变分自编码器启发，将扩散视为学习逐步去除噪声的过程：通过求解一个个小规模的去噪目标，共同教会模型将噪声还原为数据。*基于 score 的视角*源于基于能量的建模，学习随时间演化的数据分布的梯度，从而指明如何推动样本朝更可能出现的区域移动。*基于流的视角*与归一化流相关，将生成视为沿着一条平滑路径运动的过程，在学得的速度场作用下，使样本从噪声移动到数据。

这些视角具有共同的基础：一个学得的、随时间变化的速度场，其对应的流将简单先验传输到数据。有了这一基础，采样就相当于求解一个微分方程，使噪声沿连续的生成轨迹演化为数据。在此基础上，本书讨论了用于可控生成的*引导*、用于高效采样的*高级数值求解器*，以及受扩散启发的*流映射模型*，后者学习这条轨迹上任意时刻之间的直接映射。

本书面向具备基本深度学习背景、希望从概念和数学两方面清晰理解扩散模型的读者。书中阐述这一领域的核心原理，解释统一其多种表述的思想，并为进一步研究这个快速发展的领域奠定坚实基础。因此，本书既可作为研究者理解原理的参考资料，也可作为学生和初学者易于上手的入门读物。本书的补充材料可在本书网站获取：
