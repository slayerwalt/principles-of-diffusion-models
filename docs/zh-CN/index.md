# 中文翻译计划

本项目目前正在将 *The Principles of Diffusion Models* 的英文原版转换为分章节的网站，版本固定为 [arXiv:2510.21890v3](https://arxiv.org/abs/2510.21890v3)。已开始转换的[第 1 章英文样章](../en/chapters/01-deep-generative-modeling/index.md)用于检查正文、公式、图片和引用在网页中的显示效果。

英文版完成转换和校对后，再建立与英文版对应的中文章节。翻译时将保留章节结构、公式编号、图片编号和引用标识，同时维护术语表，并记录每章译文对应的英文版本。

当前页面仅记录翻译计划，尚无中文正文。可在[全书目录](../en/book-outline.md)查看英文内容的迁移进度。
