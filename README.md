# The Principles of Diffusion Models 网页版

[English](https://slayerwalt.github.io/principles-of-diffusion-models/) · [简体中文](https://slayerwalt.github.io/principles-of-diffusion-models/zh-CN/)

本项目将《The Principles of Diffusion Models》按章节整理为中英文网页，以 arXiv `2510.21890v3` 为版本依据。两种语言均包含书前材料、第 1–12 章、分部导读、附录 A–D 及全书目录，可通过顶部语言按钮切换，并保留当前章节与锚点。原图中的英文、人名和参考文献保留原文；前言、各章和附录所引文献统一维护于参考文献总页。
