# The Principles of Diffusion Models 网页版

[在线阅读](https://slayerwalt.github.io/principles-of-diffusion-models/)

本项目将《The Principles of Diffusion Models》的英文内容按章节整理为网页，以 arXiv `2510.21890v3` 为版本依据。目前已整理书前材料、第 1–12 章、第二部分未编号开篇、分部导览图、附录 A–D 及全书目录。前言、各章和附录保留其引用文献，全书统一参考文献的整理方式待定。英文版完成并校对后，再开展中文翻译。
